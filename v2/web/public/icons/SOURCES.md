# 图标来源

- 既有矢量品牌图标来自 [Simple Icons](https://github.com/simple-icons/simple-icons)。Microsoft、OneDrive 和 OpenAI 取自其 [11.15.0 版本](https://github.com/simple-icons/simple-icons/tree/11.15.0/icons)。相关许可和商标说明见同目录的 LICENSE.md 和 DISCLAIMER.md。
- 京东、拼多多、迅雷与 ChatGPT 来自 [Arcticons](https://github.com/Arcticons-Team/Arcticons)，取自 [Iconify 1.2.61 数据包](https://www.npmjs.com/package/@iconify-json/arcticons/v/1.2.61)，按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 发布。使用原图形数据增补独立 SVG 根元素。
- 抖音来自 [品牌首页的 SVG](https://lf3-static.bytednsdoc.com/obj/eden-cn/ulkphgeh7nuvspognuhbo/douyin_web/img/images/logo-horizontal.svg)。[Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Douyin_wordmark.svg) 记录了来源与商标状态。
- 腾讯云来自 [Wikimedia Commons 的腾讯云商标文件](https://commons.wikimedia.org/wiki/File:Tencent_Cloud_Logo.svg)，来源为腾讯云网站。文件页面列有公有领域标识。内联颜色属性替代了源文件的静态样式类。
